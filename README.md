
## Обучающая платформа

Простая дифференциальная платформа, которая будет обладать возможностями базового картопостроения и навигации(путепостроения + картопостроения с использованием непродвинутых датчиков) и удаленного управления и телеметрии. 

### Основной функционал

1. Построении карты пройденного пути, основываясь на IMU сенсоре и одометрии
2. Построение упрощенной двумерной карты окружающего пространства, основываясь на базовых датчиках расстояния (лазерных и ультразвуковых)
3. Навигация до заданной точки (квадрата) по составленной карте
4. Управление и передача данных телеметрии на удаленное устройство управления (ПК)
